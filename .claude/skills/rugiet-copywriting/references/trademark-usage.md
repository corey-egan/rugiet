## Registered marks — use ®

Use the ® symbol on **first mention only** in any document, page, or email. After first mention, no symbol needed.

- **Rugiet®**
- **Rugiet Ready®**
- **Ditch the Pills®**

---

## Unregistered / pending marks — use ™

Use ™ (never ®) until officially registered.

- **Ready™** (when used alone, without "Rugiet" prefix)
- **ReadyRx™**
- **RD-37™**
- **Sex Score™**
- **Vacation Sex™**
- **Fighting Weight™**
- **Go From All-Star to MVP™**
- **[R-arrow logo]™** (new branding)

---

## Key rules

### 1. First mention rule
- Use the symbol only on the **first or most prominent mention** in any asset
- After first mention, no symbols needed for the rest of the document/email
- Example: "Rugiet Ready® is designed to..." (after that, just write "Ready" or "Rugiet Ready" with no symbol)

### 2. Never use ® on these
- **Ready** (alone) — only gets ™
- **ReadyRx** — only gets ™
- **Vacation Sex** — only gets ™
- Any pending/unregistered mark

### 3. Do not mix symbols in one mark
- ✅ Correct: **Rugiet Ready®**
- ❌ Incorrect: *Rugiet® Ready™*

### 4. Logos follow the same rules
- Registered logos → ®
- Unregistered logos → ™

## Pending: PERFORMANCE MEDICINE FOR MEN

- Do **not** add ® or ™ to this phrase anywhere
- Use carefully — another party has already claimed it (permission to co-use is being sought)
- Do not use for prominent placements (signs, ad campaigns, printed marketing) until permission is confirmed
- Footer usage in emails is current practice but carries risk — monitor legal status

## Quick reference for email copy

| Usage | Correct symbol | Example |
|---|---|---|
| "Rugiet" (brand name) | ® on first mention | "Rugiet® is performance medicine..." |
| "Rugiet Ready" (full product name) | ® on first mention | "Rugiet Ready® works in as little as..." |
| "Ready" (standalone product reference) | ™ on first mention | "Ready™ combines three medications..." |
| "Ready" (subsequent mentions) | No symbol | "Ready is designed to..." |
| "Go Long" (product name) | None currently registered/pending | "Go Long is formulated..." |
| "Performance Medicine For Men" (tagline) | No symbol — pending | Use without symbols |

## Impact on current flow analyses

This guide resolves the Ready® vs Ready™ inconsistency flagged across all flow analyses:

- **"Ready" used alone** → Ready™ on first mention, then no symbol. Never Ready®.
- **"Rugiet Ready" used as full name** → Rugiet Ready® on first mention, then no symbol.
- The emails that were flagged for stray "Ready®" were correct to flag — "Ready" alone should never carry ®.
