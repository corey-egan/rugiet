## How to use these files

### For copywriting
- Each file is self-contained — no cross-references required.
- Compound entries follow a consistent template: **Forms**, **Description**, **Suggested Dosing**, **Benefits**.
- The Benefits sections provide a starting vocabulary for benefit-led copy. They are **not** defensible clinical claims — run every claim through the compliance checklist before using in patient-facing content.
- Category descriptions at the top of each file provide framing language useful for educational content, onboarding sequences, and category landing pages.

### For strategy work
- The table above maps compounds to Rugiet product relevance — start there when building campaigns around specific products.
- Cross-category compounds (e.g., NAD+ touches cellular health, longevity, and cognitive) can anchor cross-sell or "whole patient" retention narratives.
- The `compounding-pharmacy.md` file provides trust/credibility language for differentiation messaging vs. OTC supplements.
