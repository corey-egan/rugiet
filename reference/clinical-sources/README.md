## Usage rules

1. **Source language is marketing copy, not peer-reviewed evidence.** Every claim requires a clinical evidence audit before use in patient-facing content.
2. **Dosing information is reference only.** Rugiet's medical team determines all dosing for Rugiet products — never reproduce source dosing in patient communications.
3. **Cross-reference with Rugiet product catalog.** Not every compound listed here is a Rugiet product. Use the relevance column in the handouts index to identify which compounds map to active SKUs.
4. **When in doubt, flag for medical review.** If a benefit claim feels like it stretches beyond what Rugiet can defend, it probably does.
