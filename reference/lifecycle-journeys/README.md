## How to reference a specific flow

When you need to analyze or reference a specific flow (e.g., "analyze the current Ready welcome flow"), use the Figma MCP tools with the file key and node ID from the tables below:

1. **`get_screenshot`** — visual snapshot of the flow
2. **`get_metadata`** — structural XML of every frame, text node, and component in the flow
3. **`get_design_context`** — full design context including reference code

Example: to analyze the Ready welcome emails, use `fileKey: "luQdtOfoEljv6TPkwegtFR"` and `nodeId: "1601:3432"`.
